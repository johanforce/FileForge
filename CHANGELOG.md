# Changelog

## 1.0.0

- Introduce a stable application version constant and display the version in the main window and About dialog.
- Add Vietnamese and English interface languages with a persistent language preference.
- Keep compression settings language-independent by storing stable internal values rather than translated display labels.
- Add the MIT license for FileForge source code and a separate third-party acknowledgment inventory.
- Add an English README and update the Vietnamese product documentation.
- Include regression tests for translations, language switching, and preference persistence.
- Continue to include desktop preferences, local task history, diagnostics, system-tray integration, and safe cooperative task cancellation.
